# Локальный go2rtc

Превращает RTSP камеры в поток, который умеет браузер (WebRTC / MSE).

```bash
pnpm go2rtc:up
```

Дальше:

1. Открой http://127.0.0.1:1984 — морда самого go2rtc
2. В Smartosa: карточка камеры → RTSP URL → **Отдать RTSP в go2rtc**
3. Режим просмотра: **go2rtc**

Остановка: `pnpm go2rtc:down`

Пароли камер пишутся только в `config/go2rtc.yaml` (в git не попадает) или через кнопку в морде.
